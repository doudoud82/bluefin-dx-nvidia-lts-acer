# bluefin-dx-nvidia-lts-acer
This repository is meant to set up my personal device, Acer A515-51G-50RD i5-8250U 1.6Ghz quad core, Intel UHD 620, 20GB RAM, NVIDIA MX-130 2 GB VRAM.

It uses Bluefin-DX-nvidia-open as a base from the universal blue project.

For more information, check [README.old.md](README.old.md) from the template repo.

> [!NOTE]
> This personal distribution of bluefin will remain active as my main laptop OS until NVIDIA 580 akmods stop being shipped by ublue. At that point, I will see if I can still install the 580 Drivers or simply switch to another distribution that is easier to get 580 working on.
