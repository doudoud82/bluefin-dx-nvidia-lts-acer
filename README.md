# acer
This repository is meant to setup my personal device acer A515-51G-50RD i5-8250U 1.6Ghz quad core, Intel UHD 620, 20GB RAM, nvidia mx-130 2GB VRAM.

It uses bluefin-dx as a base from universal blue project from a GNOME based system.

For more information check [README.old.md](README.old.md) from the template repo.
